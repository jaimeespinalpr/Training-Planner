# Training Planner design system

- **Direction:** energetic training lab, not generic SaaS.
- **Palette:** ink `#07131f`, paper `#f6f8f5`, wrestling green `#16845c`, lime action `#c9f36b`, orange emphasis `#ff754d`.
- **Interaction:** one primary action per surface, pill track navigation, large touch targets, short mobile forms.
- **Responsive rule:** under 650px, single-column cards, sticky compact header, horizontally scrollable track tabs.
- **Accessibility:** semantic labels, visible focus should be added before production, status uses text in addition to color.
